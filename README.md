# Student Management System

A beginner-friendly Student Management System made using C++.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Student ID
- Student Name
- Age
- Course
- Marks
- Pass/Fail Result
- Grade
- Save student data in a file

## Technologies Used

- C++
- File Handling
- Vector
- Structure
- Basic OOP/Programming Concepts

## How to Run

1. Open the project in VS Code.
2. Compile the C++ file.
3. Run the program.
4. Choose an option from the menu.

## Future Improvements

- Login system

This project was created to practice C++ programming, file handling,
